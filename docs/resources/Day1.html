2) NGS and Omics

Omics data is generated by NGS

① NGS

next-generation sequencing

  • massive parallel

  • high-throughput

  • scalable & cost-efficient

What is difference between Sanger Sequencing and Next-Generation Sequencing (NGS)?

Sanger sequencing

ddNTP with flourchromes

NGS

library preparation + sequencing by synthesis

  • Library prep & bridge amplification

  • NGS library molecule: adapter + insert

    • P5/P7 (binding to flow cell)
    • Index (Sample identifier, 6-12nt, multiplexing)
    • Primer (e.g., PolyA for mRNA, 6-mer for total RNAs)

  • sequencing by synthesis (SBS)

Single-end vs. Paired-end

② Omics data

  • holistic & comprehensive
  • high-dimensional … large p, small n
  • Multi-layered hierarchical … central dogma

FASTQ Format

  • information of sequence
  • four lines per read (n=20~30M)
@SRR21484222.626.1 626 length=51       ← Read ID 
GCCTTGGTGGTGAAATGGTAGACTGGAATTCTCGGGTGCCAAGGAACTCCA  ← Sequence 
+SRR21484222.626.1 626 length=51       ← Description 
F:FFFFFFFFFFFFFFFFFFFFFFFFFFF:FFFFFFFFFFF:,FFFFFFFFF  ← Base call quality (Phred score)

Phred Quality Score

\(Q = -10 \log_{10} P\)

Phred Score Error rate Base call accruary
10 1 in 10 90%
20 1 in 100 99%
30 1 in 1,000 99.9%
40 1 in 10,000 99.99%

2) Normalization

Why Normalization is Needed

for sample comparison

  • Library size (depth): higher sequencing depth → higher counts
  • Gene length: longer genes → higher counts

standard normalization methods for RNA-seq: TMM & RLE

  • TMM: selects a reference sample, trims extreme values, and normalizes based on a set of housekeeping genes
  • RLE: uses the median ratio of each gene relative to its geometric mean across samples as the size factor
  • Normalization factor (edgeR) / Size factor (DESeq2): library size 🔼→ counts 🔽

Normalization Methods Comparison

Method Correction Comparison Remarks
Raw Count × × edgeR/DESeq2 input
RPKM/FPKM Depth + Length Intra-sample Deprecated
TPM Depth + Length Intra + Inter-sample per-sample sum = 1M
CPM Depth Inter-sample
TMM/RLE Depth + Composition Inter-sample Standard for DEG analysis

# 7. visualization ####
## 7-1. reshaping counts (Long format for ggplot) ####
transform_to_long <- function(count_matrix, method_name) {
  as.data.frame(count_matrix) %>%
    rownames_to_column("Gene") %>%
    pivot_longer(-Gene, names_to = "Sample", values_to = "Count") %>%
    mutate(Method = method_name,
           # Log2 transformation (pseudocount: +1 for 0)
           LogCount = log2(Count + 1))
}

## applying the function ####
transform_to_long(raw_counts, "1. Raw") %>% head
transform_to_long(cpm_counts, "2. CPM") %>% head

df_all <- rbind(
  transform_to_long(raw_counts, "1. Raw"),
  transform_to_long(cpm_counts, "2. CPM"),
  transform_to_long(rpkm_counts, "3. RPKM"),
  transform_to_long(tpm_counts, "4. TPM"),
  transform_to_long(tmm_counts, "5. TMM (edgeR)"),
  transform_to_long(deseq_counts, "6. DESeq2")
)
head(df_all)
